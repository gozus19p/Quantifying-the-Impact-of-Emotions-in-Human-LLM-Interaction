Developer --> Dataset : Provide input data
Dataset --> Tokenizer : Preprocess and tokenize
Developer --> LoRAModel : Load base model and apply LoRA
Tokenizer --> Trainer : Pass tokenized dataset
LoRAModel --> Trainer : Provide fine-tunable model
Trainer --> LoRAModel : Save trained model and tokenizer
